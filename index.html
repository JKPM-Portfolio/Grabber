Automated Pincer Gripper System

A stepper-driven, sensor-safeguarded gripper built to practice electromechanical wiring, multi-sensor hardware integration, and firmware/host-software control across C++ and Python.

Project Summary

This project is a linear pincer arm. It utilizes a two-phase stepper motor to drive a lead screw and move an aluminum bracket forwards or backwards.

As my first Arduino-based project, its purpose is to demonstrate a basic understanding of hardware integration through wiring and soldering, as well as computer programming across multiple languages, in order to integrate multiple hardware components into a single system controlled by a simple user interface.
